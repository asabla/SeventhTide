# Art direction

The first study uses maritime copperplate engravings, black water, muted sea green, and a single warm light. Use silhouettes that remain clear on a phone. Keep all names, rules, and costs in the interface so a balance change does not require another illustration.

Both originals were created with the built-in image generator. The web client uses smaller JPEG exports. The three salvage illustrations share a single plate, with one object per third. Keep the full-size PNG files as references for the next batch.

## First water

Source file: `first-water.png`. Web export: `web/assets/first-water.jpg`.

> Create a single wide landscape illustration for Seventh Tide, a maritime folk-horror tabletop card game. An antique copperplate engraving printed with carbon-black ink, pale bone and desaturated sea-green on worn paper. A tiny awkward lashed timber raft with two exhausted oilskin-clad figures and a single small amber lantern, a third sailor swimming tethered alongside reaching for a sealed ration tin bobbing in foam. A distant sinking steamship almost swallowed by a pale fog bank; inky curling crosshatched swells in foreground. Readable bold silhouettes, generous pale sky, intricate hand-engraved linework. Museum print quality, gritty and restrained, no typography, no lettering, no borders, no UI. Landscape 3:2, frame the raft and swimmer together near the center to allow a wide crop.

## Salvage

Source file: `salvage.png`. Web export: `web/assets/salvage.jpg`.

> A single antique maritime engraving specimen plate, landscape 3:2, designed to split into three equal-width vertical panels. In each third, ONE isolated object centered on the same warm bone lightly weathered blank paper. Left third: a tall stack of three sealed cylindrical old plain ration tins bound by cord. Middle third: a compact roll of dark sail canvas tied with twine. Right third: two broken wooden ship spars crossed and coiled with rope. Each object fits within its own third with generous blank margins on all sides. Use carbon-black and muted sea-green crosshatched engraved linework, dark outlines, any rust restrained amber, dramatic museum quality copperplate illustration as for a grim 1890 nautical survival card game. No letters, words, labels, frame, separators, backgrounds, people, UI or watermark. All three objects have strong individual silhouettes at small size.
