# Review Seventh Tide UX

Read the [UX guide](../../../docs/ux.md). For illustrations, also follow the [game art skill](../seventh-tide-game-art/SKILL.md).

1. Identify the latest approved reference and the player seat and tide phase that show the issue. Open that state in the running game with the built-in Browser. Inspect the current layout, asset, and interaction before editing.
2. Choose the existing game surface that serves the same purpose. Compare the change alongside its neighbors in the scene, including the paper, wood, or metal it sits on and the contrast of its type.
3. Verify the new design in the running game at desktop and phone viewport widths. Inspect the actual crops and sizes of the assets. Use the control through its result, including relevant selection, focus, dismissal, and waiting states. For player-visible changes across seats, check another seat.
4. Repeat the browser check after corrections. Capture the final state and resulting interaction, with enough context to show how they fit on the raft.
5. Post the evidence in a separate PR comment with a brief caption. Describe any check you could not complete.
